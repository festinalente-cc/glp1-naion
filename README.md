# GLP-1 y NAION: versión para evaluación

Sitio estático (un solo archivo, `index.html`) con cuatro vistas: inicio, médicos, público general y comunicado.
Contenido no definitivo, con corte al 18 de noviembre de 2026. Lleva `noindex` para que los buscadores no lo listen.

## Publicar con GitHub Pages
1. Crear el repositorio (por ejemplo `glp1-naion`) y subir `index.html`, `.nojekyll` y este archivo a la rama `main`.
2. Settings > Pages > Source: Deploy from a branch > `main` / `/ (root)`.
3. La página queda en `https://<usuario-u-organización>.github.io/glp1-naion/`.

Pages gratis exige repositorio público. Con enlace no listado y `noindex` no aparece en buscadores, pero cualquiera con el enlace la ve.
